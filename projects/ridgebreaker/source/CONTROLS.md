# Controls and driving guide

| Keyboard            | Action                                                         |
| ------------------- | -------------------------------------------------------------- |
| W / Arrow Up        | Accelerate forward                                             |
| S / Arrow Down      | Brake forward motion, then reverse                             |
| A / Arrow Left      | Steer left                                                     |
| D / Arrow Right     | Steer right                                                    |
| Space               | Handbrake, with reduced lateral grip                           |
| Left or Right Shift | Boost while accelerating                                       |
| E, held             | Pull toward an eligible uphill anchor; release to detach       |
| R                   | Recover at the latest camp and restore bridge slabs            |
| C                   | Chase → cinematic → hood → side → orbit                        |
| U                   | Open upgrades; purchases require proximity to the current camp |
| Escape              | Pause / resume, or close a dialog                              |

Start and Continue require a click. Click the game after interacting with another app if keyboard input is not reaching it. There are no touch driving controls.

Standard gamepad API mapping: RT accelerates, LT brakes/reverses, left stick steers, A handbrakes, B boosts, X winches. Physical controller hardware has not been tested. There are no controller-only menu, reset, or camera bindings yet.

## Driving tips

- Use short throttle inputs through the first rocks. A smooth approach is safer than full boost.
- Keep momentum in mud; upgrade tires if you want to explore its edges.
- Orange flags and the HUD identify the main expedition. Side trails carry extra salvage.
- Commit to the timber bridge once you enter; slabs collapse shortly after contact. The east bypass is longer and safer.
- Approach the upper ramp around world Z 472 with boost for a real airborne jump.
- Hold E near camp posts or selected large trees to pull uphill. The system chooses the furthest eligible anchor along the expedition direction.
- R is always available. Camps save permanently in this browser, while recovery also restores some health.

The orbit camera turns automatically. Mouse orbit is not implemented.
