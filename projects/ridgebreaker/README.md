# Ridgebreaker: Wild Ascent

[Play the game](https://nahmad0.github.io/projects/ridgebreaker/) · [Source and documentation](source/README.md)

A browser 3D off-road adventure built with TypeScript, Three.js and Rapier. Explore the Forgotten Ridge, recover salvage, upgrade the truck, and reach the summit.

This directory contains the production build for GitHub Pages. Editable source, tests, the original reference sketch, and development documentation are in [`source/`](source/). Read [`source/DEPLOYMENT.md`](source/DEPLOYMENT.md) before replacing build files.
