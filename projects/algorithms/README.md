# Algorithm Workbench

Find the maximum-sum contiguous subarray and explore the source behind sorting benchmarks and union-find constraints.

[Open the project](https://nahmad0.github.io/projects/algorithms/) · [Project directory](https://nahmad0.github.io/)

## Run locally

Serve the repository root with a static HTTP server and open /projects/algorithms/. No packages, API keys, or paid server are needed for this browser edition. Shared UI and tested algorithms are in ../shared/.

## Scope

The interactive maximum-subarray demo uses a linear scan. Original Python sorting, divide-and-conquer, and union-find coursework is in source/.
