Maximum-sum subarray

Given a sequence, find the contiguous segment with the largest total. Negative values are supported. For equal maximum sums, this demo keeps the earliest result it finds.

More from the coursework
The source collection includes insertion, merge, and heap-sort comparisons; the original divide-and-conquer maximum-sublist solution; and a union-find party arrangement solver. The browser demo uses a linear-time maximum-subarray scan so results appear immediately.
