# Original algorithm coursework

These Python programs are preserved as coursework examples, including their source-attribution comments. The browser adaptation is in `../../shared/`.

- `maximum_sublist.py`: run with Python 3, then enter `numbers.txt` when prompted. Each line after the first is a separate input sequence. The first line counts sequences.
- `party_arrangement.py`: run from this directory with Python 3. Reads `partyinfo.txt`. The included fictional sample produces YES, NO, and ERROR queries.
- `sorting.py`: runs insertion/merge/heap comparisons and appends results to `Comparisons.csv`. Its original sample sizes can be expensive; review `n_sample` before running a full benchmark. Referenced algorithm sources are retained in the file.

Only the browser algorithms were validated for this release. These original programs are supplied for inspection and local experimentation.
