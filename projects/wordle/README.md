# Wordle Pattern Analyzer

Filter five-letter words using green, yellow, and gray feedback. Repeated letters are scored in two passes.

[Open the project](https://nahmad0.github.io/projects/wordle/) · [Project directory](https://nahmad0.github.io/)

## Run locally

Serve the repository root with a static HTTP server and open /projects/wordle/. No packages, API keys, or paid server are needed for this browser edition. Shared UI and tested algorithms are in ../shared/.

## Scope

Browser adaptation of the C++17 analyzer. Original source is in source/. The unlicensed original dictionary is excluded; the app uses a small demonstration list and supports local custom lists.
