# SOC Analyst CTF

A four-stage investigation lab connecting SIEM alerts, Windows processes, persistence, network events, and identity evidence.

[Open the project](https://nahmad0.github.io/projects/soc-ctf/) · [Project directory](https://nahmad0.github.io/)

## Run locally

Serve the repository root with a static HTTP server and open /projects/soc-ctf/. No packages, API keys, or paid server are needed for this browser edition. Shared UI and tested algorithms are in ../shared/.

## Scope

Public case study only. The full lab, datasets, instructor answers, and deployment credentials are not included.
