# CSV Heatmap

Turn a labeled CSV into a color-coded matrix. Explore patterns with adjustable palettes, directly in your browser.

[Open the project](https://nahmad0.github.io/projects/heatmap/) · [Project directory](https://nahmad0.github.io/)

## Run locally

Serve the repository root with a static HTTP server and open /projects/heatmap/. No packages, API keys, or paid server are needed for this browser edition. Shared UI and tested algorithms are in ../shared/.

## Scope

Browser adaptation of the original R/Shiny CSV heatmap. The original public repository is https://github.com/nahmad0/Heatmap. Uploaded CSVs stay in the browser.
