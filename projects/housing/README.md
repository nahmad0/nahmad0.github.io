# Ames Housing Explorer

Explore 1,460 historical Ames home sales. Filter by neighborhood, home style, garage type, and construction year.

[Open the project](https://nahmad0.github.io/projects/housing/) · [Project directory](https://nahmad0.github.io/)

## Run locally

Serve the repository root with a static HTTP server and open /projects/housing/. No packages, API keys, or paid server are needed for this browser edition. Shared UI and tested algorithms are in ../shared/.

## Scope

Browser adaptation of the original Angular/Spring Boot housing project. The hosted demo calculates locally; it does not demonstrate a live Java API. Dataset attribution is in DATA.md.
