# Dataset attribution

A reduced 10-column extract of 1,460 training observations from Kaggle House Prices: Advanced Regression Techniques, based on the Ames Housing dataset compiled by Dean De Cock. Retained fields: Id, Neighborhood, GarageType, GarageArea, GarageCars, HouseStyle, YearBuilt, Heating, PoolArea, SalePrice. Missing garage type is None. Sale prices are unchanged.

Source: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data

Original dataset paper: Dean De Cock (2011), Ames, Iowa: Alternative to the Boston Housing Data as an End of Semester Regression Project. This extract supports the educational portfolio analysis; it is not a current price feed.
