# Pathfinding Playground

Compare Dijkstra and A* on the same weighted grid. Edit obstacles and watch how each search explores the board.

[Open the project](https://nahmad0.github.io/projects/pathfinding/) · [Project directory](https://nahmad0.github.io/)

## Run locally

Serve the repository root with a static HTTP server and open /projects/pathfinding/. No packages, API keys, or paid server are needed for this browser edition. Shared UI and tested algorithms are in ../shared/.

## Scope

JavaScript adaptation of the Python weighted-grid playground. The original Python implementation is in source/. Entry costs are positive integers; walls have value zero.
