## Hosting

Static files served by the existing GitHub Pages deployment. No new private Actions workflows or paid backend services.

## Validation

Run `node --test projects/tests/core.test.mjs` from the repository root.

## Not deployed here

The original Spring Boot/PostgreSQL backend, Socket.IO multiplayer games, R/Shiny runtime, and full Elastic training lab need server hosting. Their browser adaptations/case study above do not claim that those backends are online. Networked Java/Python games and private career data are not published in this collection.
